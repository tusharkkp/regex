## [1.0.0] - 2025-05-01

### Added
- `index.html`: Main application with HTML, CSS, and inline JavaScript
- `validation.js`: Core regex-based validation logic with DFA/NFA theoretical foundation
  - File name validation for `.jpg`, `.jpeg`, `.png`, `.pdf`, `.docx`
  - Email address validation using RFC-compliant regex
  - Interactive Regex Tester
  - DFA/NFA state diagram visualization
- `Group_Report.pdf`: Full project report for Theory of Computation mini project
- `Test_Report.pdf`: Comprehensive test cases and results
- `Theory_Supplement.pdf`: TOC theory documentation (Regular Languages, Finite Automata)
- `README.md`: Initial project documentation
- Deployed on Netlify: [tushar-toc-regex.netlify.app](https://tushar-toc-regex.netlify.app/)
